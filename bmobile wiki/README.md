# BMobile System Documentation

Welcome to the BMobile system documentation. This custom Android ROM is built on LineageOS with enhanced privacy and security features.

## Features

- **Privacy-Focused**: Includes privacy-enhancing applications
- **Secure by Default**: Hardened security configurations
- **Open Source**: Fully auditable and transparent
- **Custom Apps**: Pre-installed privacy-focused applications

## Included Applications

### Browser
- **DuckDuckGo**: Privacy-focused web browser with built-in tracker blocking

### File Management
- **Fossify File Manager**: Open-source file manager with root access support

### Gallery
- **Fossify Gallery**: Privacy-focused gallery app with no ads or tracking

### Image Tools
- **Image Toolbox**: Powerful image editing and manipulation tools

### Gaming
- **TapTap**: Game discovery and download platform

### Communication
- **Session**: Decentralized, privacy-focused messaging application

## Installation

1. Download the BMobile ROM for your device
2. Boot into recovery mode
3. Perform a clean flash following standard LineageOS installation procedures
4. Reboot and enjoy your privacy-enhanced Android experience
