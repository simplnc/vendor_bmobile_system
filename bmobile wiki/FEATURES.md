# BMobile Features Overview

BMobile is a privacy-focused Android ROM built on LineageOS with enhanced security and user experience features.

## Core Features

### Privacy & Security
- **Hardened Kernel**: Security patches and kernel hardening
- **App Permissions**: Granular control over app permissions
- **Network Privacy**: Enhanced network security features
- **Data Protection**: Built-in encryption and privacy tools

### Pre-installed Applications

#### Browser - DuckDuckGo
- **Tracker Blocking**: Automatic tracker and ad blocking
- **Privacy Search**: Search without being tracked
- **HTTPS Enforcement**: Automatic HTTPS upgrades
- **No Data Collection**: Zero user data collection

#### File Manager - Fossify File Manager
- **Root Access**: Full root file system access
- **Material Design**: Clean, modern interface
- **File Operations**: Advanced file management features
- **Privacy-Focused**: No ads or tracking

#### Gallery - Fossify Gallery
- **No Ads**: Completely ad-free experience
- **Material Design**: Consistent with Android design
- **Privacy First**: No data collection or sharing
- **Open Source**: Fully auditable code

#### Image Toolbox
- **Advanced Editing**: Professional image manipulation
- **Batch Processing**: Process multiple images
- **Format Support**: Wide range of image formats
- **Non-Destructive**: Preserve original files

#### TapTap
- **Game Discovery**: Find new games easily
- **Direct Downloads**: Download games directly
- **No Google Play**: Independent from Google services
- **Community Driven**: User-reviewed games

#### Session Messenger
- **Decentralized**: No central servers or data collection
- **End-to-End Encrypted**: Military-grade encryption
- **Anonymous**: No phone numbers or personal data required
- **Open Source**: Fully transparent and auditable
